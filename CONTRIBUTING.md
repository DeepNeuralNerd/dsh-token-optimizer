# Contributing to dsh-token-optimizer

First of all, thank you for taking the time to contribute to this project!

## 🐛 Reporting Bugs
If you find a bug while using the plugin, please file a GitHub Issue and include as much of the following as possible:
- Your operating system and Node.js version
- The DSH core version (e.g. 0.1.5-rc.1)
- Steps to reproduce
- Expected vs. actual behavior

## 🚀 Submitting a Pull Request (PR)
1. Fork this repository and create your branch locally (`git checkout -b feature/AmazingFeature`).
2. Keep your code style consistent with the original project.
3. **Run the tests**: run `npm test` before committing to make sure your changes break nothing.
4. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
5. Push your branch to your fork (`git push origin feature/AmazingFeature`).
6. Open a Pull Request against the original repository and describe your intent in detail.
