# Security Policy

## Supported Versions

Only the latest release is currently maintained; use the newest version to get security fixes.

| Version | Supported          |
| ------- | ------------------ |
| v2.2.x  | :white_check_mark: |
| < 2.2   | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability, **please do not disclose it publicly in Issues**. Contact me privately:

- Email: zorialind@gmail.com or a GitHub DM to @Zoria-Lind
- After receiving a report, I will acknowledge it within 48 hours and assess it with a fix plan within 7 days.
- Please keep the vulnerability confidential until it is fixed and a new version is released.
